# 自动源码备份

仓库：https://github.com/Alston3825/tomato-tech-mobile-site ，分支 `main`。

本机服务：`~/.banyuexuan-project-sync/sync.py`，配置 `projects.json`；launchd 每300秒检查变化、登录时补跑，另有每日快照。只在变化或日期变化时提交，不无限制造重复提交。

覆盖：源码、需求/架构/接口/部署文档、Blender/CAD/网页模型、AI接手说明和当天自动快照。原目录不搬迁。GitHub不适合保存系统依赖、编译缓存和模型权重；这些文件不上传，需按依赖清单/原部署手册重建。

排除：.git、node_modules、虚拟环境、build/dist/tmp/cache、运行数据/客户上传、数据库、私钥、真实.env、设备凭据、APK/镜像构建物、whisper模型权重。完整本机项目档案另保留在本次约7GB离线归档；AI系统生产数据另有加密备份。

原CI工作流以文本备份到 docs/备份的CI配置，避免自动源码快照触发发布。恢复CI前请人工核对。备份分支采用独立快照提交历史，原开发Git历史由原仓库/完整本机归档保留。

新AI：clone → checkout `main` → 读 AI接手说明.md → 安装依赖 → 从本机安全配置恢复环境 → 运行验证。不得从备份仓库直接覆盖生产数据。

每日自动接手快照只记录可核验事实；当前开发任务.md应由开发者随工作更新。跨AI交接无需原聊天；对缺失的真实服务凭据/硬件如实标待配置。
